# DeliSmart Admin

Panel global de la plataforma para superusuarios del SaaS. React, Vite, TypeScript y Tailwind CSS, sobre la API de `delismart-admin-saas-back`.

## Desarrollo

```bash
cp .env.example .env.local
npm install
npm run dev
```

El panel abre en `http://localhost:5173`. El acceso es con una cuenta de superusuario creada en el backend con `python manage.py createsuperuser`.
